# NeuroSeg Core

**NeuroSeg Core** — изолированное ML-ядро для автоматической 3D-сегментации опухолей головного мозга (глиом) по данным МРТ. Сервис спроектирован для работы с сокращенным клиническим протоколом сканирования на 2 модальности вместо стандартных 4 и встраивается в медицинский контур как самостоятельный микросервис.

## О проекте

- **Бизнес-цель:** ускорить рутинную разметку очагов поражения врачами-радиологами за счет автоматического формирования 3D-масок опухоли для медицинского просмотрщика.
- **Ядро (CV):** 3D-сегментация глиом (BraTS) на базе архитектуры `SegResNet`, адаптированная под 2 входных канала на основе открытого датасета **BraTS**.

## Разработка и запуск

В проекте настроены линтеры и форматеры (Ruff). Для установки pre-commit хуков выполните:

```bash
pip install pre-commit ruff
pre-commit install
```
